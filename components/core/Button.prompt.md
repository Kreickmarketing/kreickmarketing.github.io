Square-cornered call-to-action button, set in the button typeface (Courier Prime). Used for nav CTAs, hero enrollment buttons, and mobile "Enroll Today" bar.

```jsx
<Button variant="primary" size="lg" icon="arrow">Contact Us & Enroll Today</Button>
<Button variant="outline">Login</Button>
```

Variants:
- `primary` — solid Midnight, white text (main conversion actions)
- `outline` — 1px Midnight border, transparent fill (secondary actions on light backgrounds)
- `outline-inverse` — white border/text (buttons over photography)
- `accent` — solid Orange Crush (sparing use, one CTA per view max)
- `ghost` — text-only, no border

Always square-cornered (`--radius-lg` = 0 in this system) — never rounded.
