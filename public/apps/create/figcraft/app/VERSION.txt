FigCraft web build: Clearmark's fork, based on release 0.10.0
https://github.com/Kreickmarketing/figcraft (branch clearmark-web; upstream https://github.com/storytold/figcraft)
Adds: Save and Export download in the browser, a message bridge for this page
(apps/figcraft-web/src/bridge.rs) and the Clearmark Library on the home screen
(crates/ui-egui/src/library.rs).
License: MIT or Apache-2.0 (LICENSE-MIT, LICENSE-APACHE, NOTICE). Fonts: SIL OFL (OFL-*.txt).

To update: in ~/Developer/figcraft on clearmark-web, run `trunk build --release` in
apps/figcraft-web, then replace index.html and the figcraft-web-*.js / *_bg.wasm files here with
those in dist/web. The .js and .wasm names carry a content hash, so app/apps/create/figcraft needs
no change.
